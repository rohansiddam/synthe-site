Getting started

Clone the repo, run the checker against the example packets. Two minutes, no dependencies beyond Python.

$ git clone https://github.com/rohansiddam/Synthe.git && cd Synthe

$ python3 src/handoff_check.py examples/v03/packets/valid-signed.json --registry examples/v03/registry.json --workspace examples/v03/workspace

ACCEPT claim recorded

Core concepts

The packet

A handoff is a typed JSON packet: who sends, who receives, what was done, what evidence backs it, and what the receiver may do next. Nothing free-form.

The registry

Each receiver holds a registry of agent identities and public keys. A packet's signature is verified against the registry before anything else is checked.

The ledger

Every ACCEPT is recorded with an idempotency key. The same work can never be claimed twice, even across restarts.

Approvals

Actions a packet declares must be covered by a signed approval. A bad or missing approval is a REJECT with the reason named, not a silent pass.

Reason codes

Every verdict names its reason: signature_invalid, duplicate_idempotency_key, approval_missing, and more. The complete list is in the spec.
