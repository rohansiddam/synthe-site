Quickstart

You need:

  • A GitHub repo you can admin, with your agent's system prompt in it, either in its own file or as a string in your code (up to 20,000 characters).
  • The GitHub CLI, signed in with gh auth login, and Node 20 or later.
  • A Synthe key. At Crimson Hacks, get one at the Synthe table, with $3 of credit paid by Synthe.

Then, on your default branch, in the repo:

npx synthe init

Answer its questions: what your agent should get better at, optional real messages, the checks, and automatic merges or review. The first round starts within the hour. In the morning, open the Synthe: overnight prompt report issue.

Automatic merges land on your default branch. If it deploys your app, each change goes live. Choose review at setup if that's not what you want.

What it adds to your repo

FileWhat it holds
synthe.jsonThe goal, your checks, your rules and settings
.synthe/scenarios.jsonlThe test messages
.github/workflows/synthe.ymlThe hourly job

Your key is saved as the repo secret SYNTHE_ANTHROPIC_KEY. After setup, the only file Synthe changes is your prompt. It never runs your agent's code.

Change what it aims for: synthe.json

  • checks: up to 5 plain sentences, each something a good reply does. These decide every test message.
  • brief: what your agent is for.
  • objective: what to get better at.
  • guardrails: rules it must never break.
  • policy: your business rules, copied from your prompt at setup, so the judging knows what's allowed.
  • budget: the most a run may spend (default $3).
  • "merge_rule": { "mode": "propose" }: review every change as a pull request.

Test cases: .synthe/scenarios.jsonl

One test message per line:

{"id": "s31", "input": "Can I return shoes I wore once?", "expected": "Explains worn items can't be returned and offers an exchange if they're faulty", "split": "train"}

expected describes a good answer in a sentence. split is train (Synthe learns from it) or holdout (kept hidden to check its changes). Adding cases to a finished run starts it again at the next hourly check.

Commands

CommandWhat it does
npx synthe initSet up this repo and start
npx synthe statusShow where it is
npx synthe stopStop it. Nothing more runs or changes
npx synthe restartStart it again, after stop or once you've fixed what stopped it
npx synthe tryRun one round on your machine, changing nothing (needs ANTHROPIC_API_KEY)
npx synthe try --noiseCompare your prompt with itself, to see how much the judging varies

Coming in the next release
npx synthe calibrate will check that your checks are marked the same way each time and the way you mean them, and help you reword any that aren't.

Review mode and your default branch

With automatic merging, a winning change is merged into your default branch as soon as it wins. In review mode, Synthe opens a pull request and waits; nothing else runs until you merge or close it. Repos that require reviews get review mode automatically.

Every change can be undone with Revert on its pull request. Before you edit the prompt yourself, pull the latest changes.

Remove it

Run npx synthe stop, then delete synthe.json, .synthe/ and .github/workflows/synthe.yml, and the SYNTHE_ANTHROPIC_KEY secret.
