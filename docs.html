Get started with Synthe

A short quickstart for hackathon teams. Everything else is in the README on GitHub.

At the event? Come find us outside WEB 1230 before you start. We'll give you your event code and team code, which let Synthe run on our API key, and help you get running.

What you need

  • A GitHub repo you can admin, with your agent's system prompt in it, as its own file or a string in your code.
  • The GitHub CLI, signed in with gh auth login, and Node 20 or later.
  • Your event code and team code, for Synthe's API key. Come find us outside WEB 1230 to get them. Or use your own Anthropic key, and you need neither code.

Set it up

On your main branch, in the repo, run:

$ npx synthe@latest init

Say what your agent should get better at, confirm the checks Synthe proposes, paste your codes or key, and choose automatic merges or review. When the run ends, open the Synthe: prompt report issue in your repo.

Using Claude Code, Cursor or Codex? Tell it:

Set up Synthe in this repo. Run npx synthe@latest guide and follow it.

Merge settingAutomatic merges land on your main branch. If it deploys your app, choose review.

While it runs

CommandWhat it does
npx synthe statusShow where it is
npx synthe stopStop it. Nothing more runs or changes
npx synthe restartStart it again after a stop

You can keep editing your prompt. After Synthe changes it, pull before you edit.

Your data at the event

During the event, Synthe shares your prompt, your test cases and how the run goes with the Synthe team. It never sends your code, and it removes keys, emails and phone numbers first. Turn it off any time with "share": "none" in synthe.json. Details in the README.

Stop or remove it

Run npx synthe stop at any time. To remove it, also delete synthe.json, .synthe/ and .github/workflows/synthe.yml, and the repo secrets Synthe saved (SYNTHE_EVENT_CODE and SYNTHE_TEAM_CODE, or SYNTHE_ANTHROPIC_KEY). To undo a change, click Revert on its pull request.
