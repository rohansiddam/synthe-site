# Font licenses

Every font on synthe.live is self-hosted from this folder. All four families are licensed under
the SIL Open Font License 1.1, which allows bundling, embedding and redistributing them with a
website. The `.woff2` files are unmodified copies of the Latin and Latin Extended subsets that
Google Fonts serves, downloaded on 2026-10-06 (Archivo, the variable font with its width axis, on 2026-11-02).

| Family | Used for | License |
|---|---|---|
| Archivo | Text and headlines | [OFL-archivo.txt](OFL-archivo.txt) |
| Fraunces | Archived pages only (the name now resolves to Archivo) | [OFL-fraunces.txt](OFL-fraunces.txt) |
| Hanken Grotesk | The wordmark | [OFL-hankengrotesk.txt](OFL-hankengrotesk.txt) |
| IBM Plex Mono | Code, reason codes, labels | [OFL-ibmplexmono.txt](OFL-ibmplexmono.txt) |
