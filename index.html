Solve mode · new in 1.11.0

Improve anything a command can score.

Code, config, docs or data. You name the files, the command that scores them, and what must not break. Synthe keeps only the changes that raise the score, on a new branch.

Try it in one minute, with no key

git clone https://github.com/synthelabs/synthe && cd synthe && npx synthe@latest solve examples/date-regex/problem.json

On your own repo: npx synthe@latest problem init. Read the Solve docs

On 10 recent real bugs and slowdowns from open-source projects, Synthe found a real improvement in all 6 cases it could run, kept no fake gains, and in one case wrote the same fix as the maintainer. In a parser slowdown, its fix was about 21 times faster than before, as fast as the maintainer’s.

Before you install

What does a run cost?

You pay your model provider, on your own key; free tiers work too. Prompt mode stops at a $3 budget by default. Solve mode can run on your Claude Code or Codex plan.

Which models does it use?

Claude by default, or any OpenAI-compatible API: OpenAI, Gemini, Groq, OpenRouter, Together, or a model on your machine. In Solve mode, Claude Code or Codex can propose the changes.

Where does it run?

Prompt mode runs in your repo’s GitHub Actions. Solve mode runs on your computer and never touches your working tree.
