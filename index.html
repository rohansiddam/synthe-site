You set the bar

Point at the chart and the bar follows. Drag the handle, tap on a phone, or use the arrow keys. A change turns green when it clears your bar, and only a change that clears it can merge.

Your checks

You say what good looks like, in plain language.

Clear wins only

A change must beat the current prompt on your checks and on held-out cases.

Hard rules hold

A change that adds a rule break does not merge.

Still watched

A kept change has to keep winning. When it loses, it comes back out.

What lands in your repo

Only the prompt changes. A clear win merges as a pull request with its evidence attached, and the morning report is posted where your team already works. Your code, your tools and your data stay untouched.

Before you install

What it costs, where it runs, and what leaves your repo.

Read the full data section

What does a run cost?

You set a budget in synthe.json, and a run stops when it reaches it. On your own Anthropic key the default is $3 a run. Every report says what the run cost.

Which models does it use?

Claude, through your Anthropic key. By default Sonnet writes changes and marks checks, and Haiku runs your prompt and judges close calls. You can change both in synthe.json.

Where does it run?

In your repo, as a GitHub Actions workflow that setup adds. A run is at most 12 rounds, about half an hour. Changes arrive as pull requests, and review mode waits for your team.

What leaves your repo?

Synthe sends Anthropic what the tests need: your prompt, the file it lives in, part of your README and the test messages. It never runs your agent’s code. With the default setting the Synthe team sees run numbers, your checks, its prompt edits and one example message, never your code. Set "share": "none" to turn that off.

What npx synthe@latest init does

  1. Finds your agent’s prompt
  2. Writes five checks from your goal
  3. Writes test messages, some held out
  4. Adds .github/workflows/synthe.yml
  5. First round runs tonight
