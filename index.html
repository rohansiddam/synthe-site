The problem

Most prompt changes are guesses.

  • You fix one answer and break three others.
  • Nobody re-tests every case by hand.
  • Nobody can say whether it got better.

Synthe tests every change against your current prompt on messages written for your agent, and keeps it only when it clearly wins on your own checks.

How it works

One small, tested change at a time.

You set the bar once. Synthe does the testing every hour while you're away. Step by step

You say what good looks like

Synthe reads your repo and proposes 3 plain checks, like "Asks for the order number before anything else." You confirm or rewrite them.

Each hour, it tries 2 edits

Your agent answers 30 test messages with the current prompt and with each edit. On each message, the reply that passes more of your checks wins.

Only clear wins are kept

An edit lands only if it wins clearly more messages than it loses, wins again on 10 it never saw, and breaks none of your rules. A later loser gets undone.

Get started

Set it up with one command in your repo.

Your prompt can be its own file or a string in your code.

npx synthe init
  • Node 20 or later
  • The GitHub CLI, signed in (gh auth login)
  • A Synthe key. At Crimson Hacks, get one at the Synthe table, with $3 of credit.
  1. Say what your agent should get better at.
  2. Confirm the checks, or rewrite them in your own words.
  3. Choose: merge clear wins automatically, or review each one as a pull request.

Setup commits 3 files. After that, the only file Synthe changes is your prompt. It never runs your code.

Automatic merges land on your default branch. If that branch deploys your app, choose review.

Questions

Straight answers, including the limits.

What does Synthe change?

Only your agent's system prompt, in its own file or as a string in your code. It never runs your code, and every change is a commit you can revert.

What does it cost?

Synthe is free and open source. You pay for the AI calls with your Synthe key, which is capped at $3. A round cost about $0.06 in the public demo run, and a run stops after 12 rounds at most.

Will it push to my main branch?

Only if you choose automatic merging. In review mode, each winning change waits in a pull request for you. Repos that require reviews get review mode automatically. npx synthe stop stops it at any time.

What doesn't it test?

The test messages are simulated and single-turn. Your agent's tools and conversations aren't run, replies come from Claude Haiku even if your app uses another model, and an AI marks the checks. A better score is a strong hint, not proof of how real users will react.

Which agents does it work with?

Any agent whose system prompt lives in a GitHub repo you can admin, as a file or a string in code. Synthe tests the prompt on its own, so the framework doesn't matter.

Who is building Synthe?

Co-founders Rohan Siddamsettiwar and Rishab Ramalingam, out of the University of Utah's Sandbox startup community.
