Your AI agent gets better on its own.

How to start

It already works in public. A demo store bot's prompt, improved and merged as a pull request.

See the public demo run

Your checks decide. In plain sentences, say what a good reply does.

  • Names the return window when asked
  • Never promises a refund the policy doesn't allow
  • Hands off to a person when unsure

Only the prompt changes. Tests are simulated, so check the results yourself.

  • src/untouched
  • tools/untouched
  • prompt.mdimproved

You choose how wins land. If your main branch deploys your app, choose review.

Each win waits in a pull request for you.

Start it with one command. At the event, it's on us.

  1. 1

    Get your codes. Come up to us, and we'll set you up with the codes you need. Or use your own Anthropic key.

  2. 2

    Run one command in your repo, on your main branch.

  3. 3

    Confirm your checks. Choose merge or review, then open the report issue when the run ends.
