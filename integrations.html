What is the same for every agent

Three things hold no matter which agent you use.

No credential

The agent holds no GitHub token and no push key. The broker, in its own account, holds the only one.

A person decides

Each push is a proposal. You read the real diff and approve it. Synthe pushes exactly that commit, and the approval can't be reused.

A receipt

Every approval and every refusal is signed and chained, so anyone can check what happened.

A plugin on its own does not protect anything. The wall is the separate account and the credential the agent does not have. Setup checks that, and says plainly whether the result is advisory, guarded or enforced.
