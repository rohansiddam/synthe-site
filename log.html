Changelog

What shipped, why it matters, and the receipts.

  • October 7, 2026

    The commit broker goes public

    Synthe v0.7 is public: the commit broker that holds the credentials, a one-command setup that makes it enforced on macOS (the broker as its own user, the agent in its own account with no GitHub access), an OpenClaw plugin, and a plain git push from any agent that becomes a proposal you approve. The spec, checker and everything you install are open source under Apache-2.0; the broker is source-available under FSL-1.1. The pull request · How it's licensed

  • October 6, 2026

    The site leads with the commit barrier

    synthe.live now says what Synthe is: the commit barrier for AI agents. Agents propose, Synthe commits, anyone can verify. New: race two agents for one commit, a docs section on how the barrier works with the complete reason-code list, and honest limits on the status page. The site now loads nothing from anyone else: fonts are self-hosted, and every number comes from one file that is checked against the public repo.

  • October 5, 2026

    Public checker v0.5

    Approvals can pin the exact target of an action, like a branch, so they can't be pointed somewhere else (approval_params_mismatch). Approvals can arrive after work starts, and nothing commits without one. Handoffs can wait for other handoffs to finish (depends_on), and a receiver can refuse overlapping work (claim_conflict). 57 public tests pass. The pull request

  • October 2, 2026

    The site becomes a proving ground

    Three interactive demos ship, all running in your browser: forge this handoff (six attacks, six reason codes), the contract playground (watch a signed handoff get checked, then break it five ways), and the tamper-evidence demo (break a hash chain, find the broken block). Docs gained the full reason-code reference, and every claim on the site now links to its receipt.

  • October 1, 2026

    Exactly-once, proven on real runners

    Three runs dispatched back to back on real GitHub runners. Exactly one ACCEPT flipped to COMPLETED; the other two were rejected as duplicates with code duplicate_idempotency_key. The same work cannot be claimed twice, even across restarts. ACCEPT run · duplicate 1 · duplicate 2

  • September 30, 2026

    Two runners, one claim

    Exactly one ACCEPT across two real-runner runs; the second was rejected as a duplicate. The completed-state restore path was fixed and re-verified, so a crashed receiver cannot double-claim on recovery.

  • September 30, 2026

    The checker goes public

    Spec, checker, GitHub Action and tests are public at github.com/rohansiddam/Synthe, under an evaluation license. Read the rules before you trust them.
