The problem

An agent with a token can push anything.

  • Straight to main, at 3 a.m.
  • Over someone else's work.
  • With no record of who said yes.

With Synthe, agents hold no credentials at all. They can only propose. The broker runs as its own user, holds the only token, and acts only on a change a person approved.

How it works

Two halves. It only ships when they meet.

The mark is the system: the agent's half proposes, your half approves, and the change goes through only when both lock.

The agent proposes

It works on its own branch and proposes the push, through the plugin or a plain git push. It never holds a GitHub token, not even to read.

You approve

You see the broker's own diff, not the agent's summary, and approve with Touch ID or your passphrase. The approval names that exact commit.

Synthe commits once

It re-checks everything at the moment of commit, pushes exactly that change if nothing moved, and signs a receipt. Refusals get receipts too.

Install

Set it up once. Every push after that goes through you.

Setup asks for your approval passphrase, your GitHub token (hidden) and your admin password, then puts the agent in its own account with no credentials.

1. Set up the broker (macOS or Linux)

curl -sSL https://synthe.live/install | bash

2. Add the plugin in Claude Code

/plugin marketplace add rohansiddam/Synthe /plugin install synthe@synthe

Run Claude Code in the agent's account for the enforced setup. In your own account, which has your GitHub login, the plugin guides the agent but isn't a wall.

1. Set up the broker and the agent's account

curl -sSL https://synthe.live/install | bash

2. Setup installs the OpenClaw plugin, skill and gateway for the agent. Chat with it there:

sudo -iu openclaw cd ~/repo && openclaw tui

Anyone can verify

Every decision is a link in a chain.

Questions

Straight answers, including the limits.

What does Synthe actually hold?

The only credential that can push: a GitHub token in a file only the broker's own OS user can read. Your agents hold none, not even to read the repository.

Is it open source?

The spec, checker, clients and integrations are open source under Apache-2.0. The commit broker is source-available under FSL-1.1-ALv2: you can read, audit and run it, but not sell it as a competing service, and each version becomes Apache-2.0 two years after release. Synthe's hosted and internal code is separate.

What can't Synthe stop?

It doesn't stop prompt injection, and it can't tell whether approved code is good: if a person approves the wrong change, Synthe pushes that change. It only controls the credentials and remotes it's configured for, so an agent's account must hold no other credentials.

Which agents does it work with?

Claude Code and OpenClaw through plugins, and any agent through a plain git push or the MCP server. Git pushes are the first action Synthe performs.

What does it cost?

Running Synthe yourself costs nothing. If you'd like help piloting it with your team, talk to us.
