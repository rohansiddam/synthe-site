      How this works

      Every run signs with a fresh Ed25519 key over Synthe's exact domain-separated canonical bytes, then runs the same seven checks in the same order as handoff_check.py, with the same reason codes. Keys are generated in this tab and never leave it. The only shortcut: each run gets a unique idempotency key, so the demo ledger never fills up.
