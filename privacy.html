Privacy

What this site collects, what the Synthe tool shares with us, and how to turn it off.

Who we are

Synthe is an open source project by two founders. The code is at github.com/synthelabs/synthe.

Founder question P1. Which legal entity is responsible for this data? Give the entity name, registered address and country. Our public sources say only "Synthe" and "two founders".

For privacy questions, email rohansiddam@synthe.live.

Founder question P3. Is rohansiddam@synthe.live the right privacy contact, or do we want a role address such as privacy@synthe.live? Today it is our published security contact.

The short version

  • This website collects nothing on its own. It has no accounts, no analytics, no cookies and no tracking pixels.
  • Synthe runs in your repo. Setup runs on your computer. Rounds run in your repo's GitHub Actions.
  • Synthe shares data with the Synthe team only at the sharing level you set. You can turn sharing off at any time.
  • The sharing levels never send your code.
  • Event credit is different. Model calls made with an event code go through a proxy that keeps them, code included.

This website

What the site collects

Nothing on its own. No accounts, no analytics, no cookies, no tracking pixels. Fonts and scripts are served from synthe.live itself.

Hosting

GitHub Pages hosts synthe.live. GitHub says it logs and stores the IP address of each visitor to a GitHub Pages site for security purposes. Read the GitHub Privacy Statement for how GitHub handles this data.

Settings saved in your browser

Some pages let you pick a light or dark theme or pause motion. The site saves that choice in your browser's local storage, under synthe-theme and synthe-motion. It never leaves your device.

The partner form

The form on the Talk to us page opens your email app with a note ready to send. Nothing is stored or sent on its own, and nothing goes to a third party. If you send the email, it reaches us at rohansiddam@synthe.live.

Founder question P4. Which provider hosts the synthe.live mailbox, and how long do we keep partner emails? We do not name the provider today.

Links to other sites

The site links to GitHub and npm. Those sites have their own privacy policies.

The Synthe tool

Where it runs

Synthe runs in your repo. Setup runs on your computer. Rounds run in your repo's GitHub Actions. Your event code, team code or Anthropic key is saved as a repo secret.

What goes to the model

To test changes, Synthe sends your prompt, the code around it and the test messages to Anthropic's API. In improve mode, it sends part of your code, up to about 60,000 characters on a big repo. With an event code, model calls go through a capped proxy (see Event credit below). With your own Anthropic key, laptop calls never reach the proxy.

Founder question P12. Do we need a section on international transfers? Anthropic and GitHub receive this data. Legal review needed.

What Synthe shares with us

You choose a sharing level with "share" in synthe.json.

LevelWhat it sends
noneNothing. Sharing is off.
numbersNumbers only.
detailRounds, checks and spend. Also your goal, your checks, Synthe's prompt edits and one example message with its replies. Never your whole prompt or test-case file. This is the default for new installs.
fullUsed during Crimson Hacks until November 9, 2026 at 23:59 UTC. It also sent the starting prompt, the full test-case file and the final prompt. After that date, full behaves like detail.

Numbers go to a private repository, synthelabs/synthe-runs. Shared text goes to a private repository, synthelabs/synthe-feedback. The Synthe team reads both.

These sharing levels never send your code. Before anything is sent, Synthe removes keys, emails and phone numbers.

Existing installs without a share setting stay off. To start with sharing off, run setup with DO_NOT_TRACK=1. To turn sharing off at any time, set "share": "none".

Founder question P6. How long do we keep data in synthe-runs and synthe-feedback? No source states a retention period.

Event credit

Event credit is different. When you use an event code, every model call from init and improve on your laptop goes through the organizers' proxy. The proxy keeps the request and the reply, and the Synthe team reads them. This applies whatever your share setting is.

  • For init, that is your prompt, the code file that holds it, part of your README, and the test cases and checks Claude writes.
  • For improve, it is a record of the run: what the terminal shows, your settings, the code changes Claude proposes and the measurements.

Keys and other secrets are removed first. With your own Anthropic key, laptop calls never reach the proxy.

Crimson Hacks tracking

For Crimson Hacks, an enrolled workflow sent a tracking receipt when it started and a final status when it ended. The receipt carried the team, the repository name and ID, the workflow run ID and attempt, timing, and the outcome the workflow reported. This applied even with your own key or with sharing off. New runs were tracked until November 8, 2026 at 23:59 UTC.

Enterprise pilot

With npx synthe pilot, data leaves your machine in two ways only. First, when a person confirms publishing a review as a pull request. Second, with --live on replay, discover or propose, which sends redacted conversations to a model provider after your team's recorded approval.
