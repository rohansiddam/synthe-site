Refused · 30 of 30

Live · October 7, 2026 · a real Mac, real GitHub

Every live attack, refused

The agent's own account attacked a real install: the broker running as its own hidden user, the agent in its own account with no GitHub access, pushing to the public test repo rohansiddam/synthe-test. Each row below is one attempt, what Synthe had to do, and what actually happened, copied from the run's report. 3 rows are controls: the normal, approved path, which has to keep working.

This is a fixed set of attacks, not proof that no other attack works. Each of the 13 refusals the broker handled left a signed receipt; the others failed before reaching it (no credential, permission denied, a broken signature).

Synthe

The trust layer for AI agents. Agents propose. You approve. Synthe commits, and anyone can verify the receipt.

Synthe is an early project. The spec, checker, clients and integrations are open source under Apache-2.0; the commit broker is source-available under FSL-1.1-ALv2. How it's licensed. Synthe produces evidence; it doesn't make anyone certified, compliant or insured.

From the Greek synthēkē, meaning agreement.
