The license provides the code "AS IS", without warranties of any kind (section 7). It also limits liability (section 8). Read the full license.

An early project

Synthe is early. There is no hosted service, no service level agreement and no price list.

What Synthe does to your repo

  • Synthe tries small changes to your agent's system prompt and tests them against the current one on simulated user messages. In improve mode, it proposes code changes instead and measures each one with a number you choose.
  • Tests use simulated messages, not real users. Check the results yourself before you rely on them.
  • Synthe merges a change into your main branch only if you chose automatic merging at setup. Otherwise it opens a pull request for you to review.
  • In improve mode, every change is made and measured in a temporary checkout. Your working tree and branch are not touched. It refuses changes to tests, the metric command, package.json, lockfiles, .github/ and config files.
  • You can undo every change. Close the pull request, or revert it after it merges.

Your part

  • Your event code, team code or Anthropic key is saved as a secret in your own repo.
  • You choose your sharing level. The privacy page says what each level sends.
  • Your own Anthropic key always wins over event credit.

Event credit

An event code lets a team use model credit through a capped proxy instead of its own key.
